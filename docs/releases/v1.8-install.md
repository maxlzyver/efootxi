## English

1. **Download the APK.** Download `efootxi-1.8.apk` via MediaFire, QQ File Transfer, or the Telegram channel. The release page lists the file size and SHA-256 checksum so you can verify the download. [1.8 release page](https://github.com/maxlzyver/efootxi/releases/tag/v1.8) · [Telegram downloads](https://t.me/efootxi)
2. **Install or upgrade in place.** You need Android 9 or later and a 64-bit ARM device. If you already have 1.7, open the new APK and install it over your existing app to keep your save. For a first-time installation, follow the Android prompt if it asks you to allow installs from your download source.
3. **Stay online for resource setup.** On the first launch, choose a patch or continue with your previous one. Wait for resource setup to finish before entering the game. The app reuses files that pass verification.
4. **Resume interrupted downloads.** The game downloads its resources from GitHub. When your connection is stable, reopen the app and resume setup. Keep the existing app, save data, and download progress. Once setup is complete, you can play single-player modes offline. Both players in a LAN match should use the same version.

If you have trouble installing or starting the app, include the app version, device model, Android version, and full error message in your report. [Telegram feedback channel @efootxi](https://t.me/efootxi)
