V1.7 完善世界杯、欧洲杯和欧冠的淘汰赛、赛程与统计，修复大师联赛冲刺版换帅和协同值问题，补齐俱乐部与联赛关联，并更新球员卡库和教练。完整公告收录 1.6 重点回顾以及补录卡、新卡和教练名单。

最低要求为 Android 9 和 64 位 ARM 设备。V1.7 安装包大小约 2.23 GB（2.07 GiB），资源通过 GitHub 下载。安装包 SHA-256 见发布页。
