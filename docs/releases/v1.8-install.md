## English


The APK is about 2.12 GiB. It requires Android 9 or later and a 64-bit ARM device.

Download `efootxi-1.8.apk` from any of these three sources.

- [MediaFire](https://www.mediafire.com/file/e8be0unwx61b370/efootxi-1.8.apk/file)
- [QQ File Transfer](https://qfile.qq.com/q/6vU1sbwqQg)
- [Telegram](https://t.me/efootxi)

1. Open the downloaded APK and install it. If Android asks for permission, allow your browser or file manager to install apps, then continue.
2. If you already have efootxi 1.7, install 1.8 over it to keep your save.
3. Stay online the first time you open 1.8. Choose Original or the patch you usually play and wait for resource setup to finish. If the download stops, reopen the game to resume it.
4. Once setup is complete, you can play single-player offline. For friend matches, make sure both players have updated to 1.8.

If you have trouble installing or starting the app, include the app version, device model, Android version, and full error message in your report. [Telegram feedback channel @efootxi](https://t.me/efootxi)
