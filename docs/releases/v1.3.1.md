# efootxi V1.3.1 更新公告

> **新版提示**：V1.5 r1525 已发布。[下载 APK（MediaFire）](https://www.mediafire.com/file/segehmvzur45tq0/efootxi-1.5-r1525.apk/file) · [查看 V1.5 更新公告](v1.5.md)。V1.3.1 可覆盖安装并保留存档；请勿卸载旧版或清除应用数据。

efootxi 第一版基于 73@7othree 版本开发，已获得修改许可。后续版本由 maxlzyver 持续修改与维护。

1. **修复自选增能闪退。** 修复打开增能列表、进入强度选择和返回列表时的问题，随机增能仍可正常使用。

2. **调整自选增能的加载方式。** 先选择增能种类，再查看该种类实际可选的「+几」及对应版本；切换列表分步刷新，不一次挤出全部配置，确认后才保存结果。

3. **继续保护球员自带增能。** 自选和随机只操作可训练的附加槽，不改变固有增能，也不把一种增能的数值强行套到另一种增能上。

4. **主界面轮播补充配图。** 新球员、新教练使用图片展示，下方标注 Telegram 发布频道和 GitHub 项目地址。

5. **初始阿根廷阵容改为控球游戏。** 斯卡洛尼带队的默认阵容使用控球游戏打法；保留已经自行修改的阵容、教练与培养结果。

6. **减少打开球员列表和训练时的等待。** 优化大量球员资料在本地的整理和传送，保留全部球员、筛选结果和训练数据，不通过隐藏球员来提速。

7. **更新页面直接展示公告。** 下载、校验资源时即可阅读当前版本更新摘要，点击「展开完整公告」查看全部内容，断网也可以查看。

8. **补齐游戏内更新通知。** 通过右上角通知图标查看本次更新内容；新公告显示未读提示，阅读后保存已读状态，不自动弹窗打断操作。

9. **V1.3 玩家可保留存档覆盖安装。** 本次沿用 V1.3 的包名和签名，可以继续与 73 共存；V1.2 及更早版本仍按独立安装处理，不继承旧存档。
